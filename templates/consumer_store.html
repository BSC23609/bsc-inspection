The Consumer Store page is ready. It reads live stock the same way as the stock MIS — a scheduled job on the SAP server reads SAP and publishes the data file the page reads. To go live, on the SAP box (RDP):

  • Run C:\scripts\refresh_consumer.ps1 -Discover once to find the Consumer Store warehouse code, set it in the script.
  • Run setup_consumer_task.ps1 to register the 15-minute refresh (writes consumer_*.csv to the bsc-stock-data repo).
  • This page starts showing live data automatically once the first refresh has pushed.
